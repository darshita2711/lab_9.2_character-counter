# Character Counter Project Reflection

In this project, I learned how to build a Character Counter application using React, TypeScript, and CSS. I practiced using the `useState` Hook to store the text entered by the user and update the statistics in real time.

I created reusable components for text input and statistics display. I also learned how to calculate character count, word count, and estimated reading time. I used conditional statements to check minimum and maximum word limits and display different messages based on the word count.

While working on this project, I improved my understanding of React components, props, interfaces, and state management. I also practiced styling the application with CSS to make the statistics and messages easier to read.

Overall, this project helped me understand how React and TypeScript work together to build an interactive application. I would like to continue improving the design and adding more features as I learn more about React.
